# 🚀 FOSSEE Workshop Booking — UI/UX Enhancement

## 📌 Project Overview

This project focuses on redesigning the existing FOSSEE Workshop Booking platform with a strong emphasis on **modern UI/UX, responsiveness, accessibility, and performance** using React.

The original platform was functional but minimal. This redesign transforms it into a **clean, intuitive, and mobile-friendly experience** tailored primarily for students.

---

## 🛠️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/FOSSEE/workshop_booking.git
cd workshop_booking
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Application

```bash
npm start
```

The app will run locally at:

```
http://localhost:3000
```

## 🧠 Design Reasoning

### 1. Design Principles Used

* **Simplicity** → Removed unnecessary clutter
* **Hierarchy** → Important actions highlighted
* **Consistency** → Uniform design system
* **Accessibility** → Usable for all users

### 2. Responsiveness Strategy

* Used **mobile-first approach**
* Flexible layouts with CSS Grid & Flexbox
* Media queries for different screen sizes

### 3. Trade-offs (Design vs Performance)

* Avoided heavy animations to maintain speed
* Limited external libraries
* Focused on lightweight UI components

### 4. Challenges Faced

* Balancing design with existing backend structure
* Making forms clean yet informative
* Ensuring responsiveness without breaking layout

**Approach:**

* Incremental UI improvements
* Tested across multiple screen sizes
* Refactored components for reusability
